# saiminjutsu-fudegaki-backrainbow-tools

Translate tools for Saiminjutsu series (Python only).

- `saiminjutsu2-fudegaki/` — Saiminjutsu 2 tools (engine: fudegaki)
  - `blackrb_spt.py`, `sj2.py`, `repack.py`, `utils.py`, `z.py`
- `saiminjutsu4-blackrainbow/` — Saiminjutsu 4 tools (engine: BLACKRAINBOW)
  - `cli.py`, `MED.py`, `SCE.py`

> Note: text/script data (`.txt`, `.spt`, `pack/`, `scr/`) are intentionally excluded from this repo.
